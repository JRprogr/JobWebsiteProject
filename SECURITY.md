# Security policy

DS[Careers] is a small non-commercial portfolio project, maintained on a best-effort basis.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to info.dscareers@proton.me with what you found and how to
reproduce it. You will get an answer as soon as possible; there is no bug bounty.

## What is (not) in this repository

No secrets: the database connection strings and the site operator's contact details live only in the hosting providers'
environment settings. If you find a credential in the repository or its history, that is exactly what this address is for.
The site has no user accounts and stores no visitor data.
